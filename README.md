##  Установка и запуск

### Шаг 1. Клонирование репозитория
Склонируйте проект на свою локальную машину:
```bash
git clone https://github.com/StanislavRudyk/practice.git
cd practice
```

### Шаг 2. Настройка переменных окружения
Создайте файл `.env` в корневой папке проекта. Вы можете скопировать следующий базовый конфиг:
```env
POSTGRES_USER=admin123
POSTGRES_PASSWORD=admin123
POSTGRES_HOST=db_postgres
POSTGRES_DB=admin123
REDIS_HOST=db_redis
REDIS_PORT=6379
REDIS_PASSWORD=redis123
SECRET_KEY=m:1h!G%\b0NrVOQ
ACCESS_TOKEN_EXPIRE_MINUTES=30
REFRESH_TOKEN_EXPIRE_DAYS=7
ALLOWED_ORIGINS=http://localhost:3000
LOGIN_RATE_LIMIT=5/minute
```

### Шаг 3. Запуск контейнеров
Соберите и запустите проект одной командой:
```bash
docker-compose up -d --build
```

**Что произойдет при запуске:**
1. Поднимется контейнер `db` с PostgreSQL.
2. Поднимется контейнер `redis`.
3. Поднимется контейнер `backend` с FastAPI.
4. При первом запуске FastAPI **автоматически создаст все необходимые таблицы** в базе данных (используется `Base.metadata.create_all`). Вам не нужно вручную запускать миграции!

### Шаг 4. Проверка работы
Убедитесь, что все контейнеры работают:
```bash
docker-compose ps
```

Теперь бэкенд доступен локально. Откройте интерактивную документацию Swagger UI в браузере:
👉 **[http://localhost:8000/api/docs](http://localhost:8000/api/docs)**

## 📦 Основные модули системы (API)

* `Auth` — JWT регистрация, логин, ротация refresh-токенов.
* `Fields & Weather` — Создание полей, получение исторических данных и гиперлокального прогноза погоды (Open-Meteo), расчет теплового стресса и влажности.
* `Calculator` — Эвристические расчеты дефицита NPK, норм высева и блокировки фосфора/азота из-за уровня pH.
* `Machinery Monitoring` — Учет тракторов, путевые листы, контроль ГСМ, выявление аномалий и сливов топлива.
* `Yield Forecasting` — Анализ почвы и прогнозирование урожайности по **Закону минимума Либиха**.
* `Warehouse Quality` — Учет силосов, контроль влажности/температуры хранения, **автоклассификация зерна по ГОСТ** на классы 1-6.
* `Offline Mode` — Снапшоты данных для работы в полях без интернета и пакетная синхронизация.
* `Reports & Export` — Годовые отчеты, "Книга истории полей", выгрузка CSV для бухгалтерии.
